# SignalR

## Course Description
This directory contains labs and resources covering **ASP.NET Core SignalR** for real-time web communication. Topics progress from basic hub setup and server-push patterns to authenticated multi-room chat with JWT, SignalR Groups, online presence tracking, and multi-client architectures spanning web and desktop.

## Labs

| Lab | Topic | Description |
|-----|-------|-------------|
| [Lab01](Lab01/) | **SignalR Fundamentals & Real-time CRUD** | Single-page student/department manager with real-time push via SignalR — all CRUD operations broadcast instantly to every connected browser tab. |
| [Lab02](Lab02/) | **Authenticated Chat with Groups & Presence** | Full-stack chat system with JWT-secured hub, room-based group messaging, private direct messages, online presence, and multi-client support (MVC web + WinForms desktop). |
